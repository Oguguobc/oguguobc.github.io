## Publish to GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io` at https://github.com/new (or use a different repository name if you prefer a project site).
2. Upload **the contents of this folder** to the repository root. **Do not upload only the ZIP.** `index.html` should appear in the repository root.
3. Commit files to the `main` branch.
4. Go to `Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `main` → `/(root)` → `Save`.
5. Visit `https://YOURUSERNAME.github.io/` (or `https://YOURUSERNAME.github.io/REPOSITORY/` for a project repository).
6. In GitHub Settings → Pages, optionally add your own domain and follow the DNS instructions.
